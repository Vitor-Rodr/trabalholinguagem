PERGUNTAS FREQUENTES

O jogo é gratuito?

Sim! "O Banquete Guloso" é um projeto totalmente gratuito desenvolvido para ser jogado diretamente pelo navegador sem custos.

Quais são os requisitos para jogar?

Um computador com um navegador moderno (como Google Chrome, Firefox ou Edge) e conexão à internet.

O jogo salva o meu progresso automaticamente?

Infelizmente não. Estamos trabalhando para aprimorar essa função o quanto antes! Foi mal...

O que faço se encontrar um bug ou ficar preso num enigma?

Podes reportar erros diretamente na nossa página de Suporte. Para ajudas sobre os enigmas, consulta a nossa página de Como Jogar ou explora as dicas deixadas nos cenários.

Quantos cômodos existem para explorar no escape room?

Vai ter que jogar para descobrir...
